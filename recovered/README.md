# Recovered Conversation Archives

This directory contains evidence recovered from earlier ChatGPT sessions about *Milo's Story / Guardians of the Elements*.

## Rules

- Each source conversation gets its own unique subdirectory.
- Never overwrite another session's archive.
- Preserve actual prose where available; do not replace it with summaries.
- Distinguish established canon, proposals, abandoned ideas, and uncertainty.
- Do not edit `canon/` or `chapters/` during recovery unless explicitly asked.
- GitHub history is part of the archive, so use a descriptive commit message for each recovery.

## Expected session package

Each session folder should normally contain:

- `ARCHIVE-REPORT.md` — overview and provenance
- `PROSE.md` — substantial story prose recovered from the conversation
- `CHAPTER-MATERIAL.md` — chapter-specific material, outlines, scenes, revisions
- `CHARACTERS.md` — character information and evolution
- `WORLD-LORE.md` — locations, magic, creatures, history, rules
- `VISUALS.md` — image prompts, character sheets, visual descriptions
- `OPEN-QUESTIONS.md` — contradictions, uncertainty, and unresolved items
